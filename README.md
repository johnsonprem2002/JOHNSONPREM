# johnsonpremb Portfolio

Responsive mechanical design portfolio built with HTML, CSS, and JavaScript. The six provided project images are stored locally in `images/`, so the portfolio does not depend on external image hosting.

## Deploy with GitHub Pages
1. Upload all files and the `images` folder to the root of your GitHub repository.
2. Open Settings → Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select `main` and `/(root)`, then Save.
5. Your site will publish at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

Contact links are configured in `index.html` for email, LinkedIn, and phone.
