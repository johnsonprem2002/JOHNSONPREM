# johnsonpremb Portfolio

A responsive, single-page personal portfolio built with plain HTML, CSS, and JavaScript. It is ready for GitHub Pages and does not require a build step.

## Preview locally

Open `index.html` in your browser. For a local server, run this from the project folder:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Publish with GitHub Pages

1. Sign in to GitHub and create a new repository named `johnsonpremb` (or another name you prefer).
2. Keep it Public if you want to use GitHub Pages for free on the standard GitHub Free plan.
3. Upload `index.html`, `styles.css`, and `script.js` to the repository's root. You can also upload this whole folder's contents.
4. Open the repository's **Settings**.
5. Select **Pages** from the left sidebar.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Choose branch `main` and folder `/ (root)`, then click **Save**.
8. Wait for the deployment to finish. Your site URL will usually be:
   `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`

For a repository named exactly `YOUR-USERNAME.github.io`, GitHub Pages uses:
`https://YOUR-USERNAME.github.io/`

## Personalize before publishing

- Replace the sample project titles and descriptions in `index.html`.
- Replace `hello@example.com` with your email address.
- Update the about section with your real background, tools, and skills.
- The abstract project artwork is made with CSS, so you can swap it for screenshots or project images later.

## Files

- `index.html`: page content and sections
- `styles.css`: layout, colors, responsive design
- `script.js`: mobile navigation and current year
